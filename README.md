# Nozavolochen docs

Documentation site for the [Nozavolochen framework](https://github.com/Nozavolochen/framework) for No Man's Sky. NMS-inspired theme using the OFL-licensed
[NMS Universal Font](https://github.com/NMSCD/No-Mans-Sky-Universal-Font).

The build also emits machine-readable copies of the docs for language models:

- `/docs/llms.txt` - the index: what the framework is and where to read next
- `/docs/llms-full.txt` - every page as Markdown
- `/docs/llms-small.txt` - the same with asides removed
- `/docs/_llms-txt/mod-authoring.txt` - the pages needed to write a mod

`src/data/framework-mods.json` is generated by
`scripts/fetch-framework-mods.mjs` and refreshed weekly. It carries each mod's
source repository, read from the link labelled `Source:` in the mod's Nexus
description.
