title: Nozavolochen
description: Declarative runtime mod framework for No Man's Sky. One DLL, many spec-driven mods.
---

`Nozavolochen` (/ˌnəʊzəvəˈlɒtʃɛn/, "convergence"): one
`xinput9_1_0.dll` hosts any number of
independent declarative mods. Each mod is a folder
with a `mod.toml` describing the pattern patches the loader applies
at game boot.

**Installing the framework?** Start with the [install guide](/docs/users/install/).

**Building a mod?** Start with [mod layout](/docs/authors/layout/).
